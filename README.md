# Яндекс: проверка применимости, 14.10.2026

Вывод: бесплатный публичный просмотр автомобильных маршрутов на карте —
документированный вариант. Первоначальная схема «живые пробки → GitHub JSON →
ChatGPT» бесплатными условиями не подтверждена. Реальный ответ Яндекса ещё не
получен: ключ не предоставлен. Прототип не выдаётся за проверенный источник.

## Лицензия

[FAQ](https://yandex.ru/maps-api/faq) допускает бесплатный JavaScript API при
соблюдении условий. [Соглашение](https://yandex.ru/legal/maps_api/ru/), пп. 4.1.1–4.1.3,
требует открытого бесплатного доступа, использования данных в рамках сервиса и
сохранения атрибуции. П. 5.1.3 ограничивает мониторинг объектов и диспетчеризацию;
планирование поездки между фиксированными точками не тождественно слежению за
машиной, но конкретный сервис нужно оценивать по назначению.

П. 5.1.5 предусматривает узкое исключение для кэширования до 30 дней ради работы
сервиса. Это не разрешение на архив в Git или передачу результатов стороннему ИИ.
Право копировать производную сводку в ChatGPT не установлено. Поэтому кнопка
экспорта дорожных значений не реализована. Ручное действие само по себе не меняет
этих условий.

П. 3.2 запрещает автоматическое получение API-ключей. Ключ должен получить
владелец вручную установленным способом. Прототип не автоматизирует регистрацию
и принятие соглашения. Общего разрешения на безнадзорный сбор через браузер для
создания внешнего набора данных не найдено.

## Документированные данные

| Возможность | Что подтверждено |
|---|---|
| Объезд пробок | `MultiRoute` с `avoidTrafficJams:true` |
| Время с пробками | `driving.Route.properties.durationInTraffic`, секунды и текст |
| Альтернативы | Коллекция `MultiRoute.getRoutes()`; количество не гарантировано |
| Перекрытия | `Route.properties.blocked`; общий признак для маршрута |
| Участки | `getPaths()` → `getSegments()`; сегменты связаны с манёврами |
| Поля участка | `street`, `distance`, `duration`, `durationInTraffic`, `action`, `text` |
| Текущая и свободная скорости | В проверенном справочнике Segment не заявлены |
| Главный затор, конец затора | Готовые поля не найдены; необходимы отдельные обоснованные алгоритмы |
| Потеря времени | Не следует считать `duration` доказанным free-flow baseline |

Источники: [MultiRoute](https://yandex.com/dev/jsapi-v2-1/doc/ru/v2-1/dg/concepts/router/multiRouter),
[Route](https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/ref/reference/multiRouter.driving.Route),
[Segment](https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/ref/reference/multiRouter.driving.Segment).
Документированное поле не гарантирует наличие данных на конкретном ответе.
Время — оценка поставщика, а не независимое измерение скорости машины.

## Минимальный прототип

`web/index.html` и `web/app.js`: карта, ввод координат, `MultiRoute`, варианты,
время с пробками, расстояние и общий признак перекрытий. Нет базы данных,
localStorage, service worker, API-ответов в Git, OpenAI API и фонового сбора.
Обновление маршрута — по нажатию. После 20 минут таблица очищается.
Слой пробок доступен штатной кнопкой карты. Атрибуция Яндекса сохраняется.

Кнопка «Скопировать ссылку» содержит только собственные введённые координаты
пользователя. Это **не** копирование полученных через API дорожных данных.
Личные точки и ключ не встроены в публичные исходники.

Для проверки введите на странице вручную полученный ключ JavaScript API 2.1,
затем координаты. Для вечернего маршрута:

- начало: координаты работы, предоставленные пользователем ранее;
- конец: координаты дома, предоставленные пользователем ранее.

В сам публичный пакет эти значения не включаются. На сайте ключ после загрузки
удаляется из поля ввода, но, как у любого клиентского API, виден в запросе загрузки
библиотеки. Ограничьте его разрешённым доменом. [Настройка ограничений](https://yandex.ru/maps-api/docs/js-api/limit.html).
Ключ сайта для всех посетителей пока не настроен: ввод ключа — временный режим
ручной проверки, а не завершённый публичный сервис для всех пользователей.

Публикация: GitHub Settings → Pages → Source: GitHub Actions; запустить
workflow «Publish Yandex browser prototype». Загружается только `web/`, без
Python-проекта, конфигурации маршрута и папки `data/`.

## Автоматическое получение в ChatGPT

Подтверждённого бесплатного способа для API-данных не найдено. GitHub Connector
читает сохранённые файлы, что не решает ограничения использования и хранения.
Скриншоты, headless-браузер и копирование результатов не создают новых прав.
Без открытой страницы JavaScript-прототип вообще не выполняет расчётов.

До включения экспорта стоит запросить у Яндекса письменное уточнение. Подготовленный
вопрос, **не отправлен**:

> Допускает ли бесплатная лицензия JavaScript API 2.1 кнопку, по которой пользователь
> копирует время своего маршрута и описание задержек для передачи в ChatGPT?
> Допускается ли автоматическая передача этих значений без хранения на нашем сервере?
> Если нет, какая лицензия разрешает такой сценарий и хранение текущей сводки в GitHub?

По исследованным условиям первоначальный полный сценарий без платных API
сейчас нельзя обещать. Проверяемый бесплатный вариант — просмотр маршрута
в интерфейсе Яндекса/на открытой странице с API. Возможность отдельного
некоммерческого соглашения с другим поставщиком не исключается, но не подтверждена.
